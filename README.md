# NetProbe · Android 网络测试工具

一款在手机端量化「WiFi 质量 → 视频起播/卡顿 → 网页时延」的测试工具，用于判断网络是否满足 4K 视频、实时会议等业务需求。

> 本仓库仅发布可安装的 APK 与使用说明，**不包含源代码**。

## 下载

最新版本见右侧 **Releases**，或直接下载：[NetProbe-v2.9.apk](./NetProbe-v2.9.apk)

- 包名：`com.netprobe.app`
- 最低系统：Android 7.0（API 24）
- 大小：约 4.6 MB

## 功能

| 模块 | 说明 |
|---|---|
| 网页时延测试 | 真实 WebView 加载页面，拆分 DNS / TCP / TLS / TTFB / DOM / OnLoad |
| 视频时延测试 | 真实播放器起播，按解码宽高校验是否真 4K，30 秒持续播放统计卡顿次数与时长，并做 HTTP Range 探测 |
| WiFi 测评 | RSSI 曲线、链路协商速率、协议标准、11k/11r/11v、国家码、信道宽度、BSS Color、同频干扰、综合评分 |
| 漫游测试 | 100ms 采样 BSSID，漫游前后切到 25ms 高频探测，精确测量业务中断时长，输出 RSSI 曲线与事件明细 |

## 安装

1. 下载 APK，点击安装（需在系统设置中允许「安装未知应用」）。
2. 首次启动请允许**定位权限**并打开系统定位开关——Android 读取 SSID / BSSID / 信号强度依赖该权限，否则无法识别 AP 与漫游。
3. 建议测试时关闭 VPN、暂停后台下载与系统更新。

## 视频片源

内置 4K / 1080p / 720p / 576p / 540p / 480p 及带宽探测共 14 条片源，支持在「自定义地址」粘贴 MP4 直链。

说明：4K 片源均为公开测试片，若测得卡顿，请先看结果中的「实测速率」是否低于片源码率（4K 约需 ≥26 Mbps）；这是带宽问题，不是手机性能问题。

受版权与防盗链保护，B 站 / YouTube / 抖音等平台链接无法在 App 内直接播放。
